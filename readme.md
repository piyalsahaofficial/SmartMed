# SmartMed

AI-powered Pharmacy Inventory and Expiry Management System.

## Current Features

- Add medicines
- View all medicines
- Search medicines
- Update medicine quantity
- Delete medicines
- Detect low stock medicines

## Tech Stack

- Python
- FastAPI
- Pydantic

## Upcoming Features

- PostgreSQL Integration
- JWT Authentication
- OCR Integration
- Barcode Scanner Support
- React Frontend
- Docker Deployment
